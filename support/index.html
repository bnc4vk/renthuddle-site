Support

RentHuddle is published by Brahe Labs. Choose the support route that fits the information you need to share.

Private support

Email bnc4vk@gmail.com for account questions, property-specific problems, privacy requests or anything containing personal information.

Email RentHuddle support

Technical bug reports

Public GitHub issues are useful for reproducible technical bugs. Include the property website, what you expected, what happened and the extension version.

Open a public GitHub issue →

Keep public reports safe.

Do not post private property URLs, property notes, OAuth information, access tokens, passwords, Google Sheet links or personal details in a public issue. Send those details by email only if they are necessary.

Before reporting a problem

  • Make sure you are using Google Chrome on a supported property-detail page.
  • Confirm that you accepted the privacy disclosure and created or selected a RentHuddle Sheet.
  • Reload the listing page after updating the extension.
  • Note whether the problem occurred during capture, review, Google sign-in, Sheet selection or saving.

Supported sites

RentHuddle supports Rightmove property pages, Zoopla sale, rental and new-home detail pages, and Zillow home detail pages.
