Privacy Policy

Effective: 22 July 2026

RentHuddle is a Chrome extension by Brahe Labs that saves Rightmove, Zoopla and Zillow listings to a shared Google Sheet. This policy explains what data the extension handles and why.

Data the extension handles

After you accept the extension's in-product privacy disclosure, RentHuddle may handle:

  • Website content and browsing activity: the URL and visible property details on supported Rightmove, Zoopla and Zillow listing pages. The extension reads these details when you choose to capture a property.
  • Form data: property details, status and notes that you review or edit in the capture form.
  • Google authentication: an access token supplied by Chrome's Identity API. The token is used only for the Google Sheets requests you initiate and is not sent to or stored by the developer.
  • Local settings: your consent choice and the ID, URL and title of your selected RentHuddle Google Sheet. These settings are stored locally in Chrome.

How the data is used

The extension uses this data solely to create or validate a RentHuddle-formatted Google Sheet and save property details that you approve. It also checks whether the current page is supported so it can enable the capture control.

Where the data goes

RentHuddle has no developer-operated server. Property details you approve are sent over HTTPS directly from the extension to the Google Sheets API and stored in the Google Sheet you select. Listing image URLs may be placed in that Sheet so Google Sheets can display the image. Google processes this data under its own privacy policy and the terms applicable to your Google account.

The developer does not receive, sell, rent, share or use your property data, Google Sheet data, browsing activity or authentication information for advertising, profiling, analytics or any unrelated purpose.

Google API Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

The extension requests access to supported property websites so it can capture listing details when you ask it to. It uses Chrome storage for the local settings described above and Chrome Identity with the drive.file scope to create, validate and update RentHuddle Sheets that the extension creates or that you explicitly select.

Retention and control

Local settings remain in Chrome until you clear the extension's data or uninstall it. Property data remains in your Google Sheet until you edit or delete it. You can delete any Sheet, revoke the extension's Google account access, clear Chrome extension data or uninstall the extension at any time.

Security

Data sent to Google is transmitted over HTTPS. The extension does not include remote code and does not expose authentication tokens to webpage scripts.

Children

RentHuddle is not directed to children and does not knowingly collect children's personal information.

Changes to this policy

If the extension's data practices change, this policy and the in-product disclosure will be updated before those practices take effect.

Contact

For private privacy questions or requests, email bnc4vk@gmail.com. For technical bugs that contain no private information, you can also open a public GitHub issue. Never post private property URLs, OAuth information, access tokens or personal details in a public issue.
